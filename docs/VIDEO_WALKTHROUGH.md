# YouTube walkthrough script

Target length: 15–20 minutes.

1. Introduction: explain the five-agent monorepo and the shared ADK configuration.
2. Setup: create a virtual environment, install requirements, configure `.env`, and run `pytest`.
3. Lead research: show a company qualification prompt and explain evidence versus inference.
4. Gemini CLI pipeline: show the explicit working directory, timeout, and failure handling.
5. MCP bug assistant: demonstrate workspace listing, safe file reads, and path traversal protection.
6. Code review: show severity-ranked findings and the testing plan.
7. Commerce: search the catalog and retrieve a product; explain why checkout is intentionally gated.
8. Production path: describe authentication, observability, secret management, Cloud Run, and CI/CD.
9. Close: show the repository structure and the commands viewers can run.

Suggested title: `Building 5 Production AI Agents with Google ADK, MCP, and Gemini CLI`.
